# d2

svugy reads d2 v0.9.0, so existing d2 files render without a rewrite.

```sh
svugy render my.d2 -o my.svg     # render as it is
svugy import my.d2 -o my.md      # convert to Markdown
```

## What maps

| d2 | svugy |
|---|---|
| `a: { b }` | `b` nested in `a` |
| `a -> b: text`, `a -> b -> c` | a labelled edge; one edge per hop |
| `a <- b` | an edge from `b` to `a` |
| `link` | `link` |
| `tooltip` on a shape or an edge | its description |
| `style.fill`, `style.stroke`, `style.stroke-dash` | fill, stroke, dash |
| `shape: rectangle`, `square` / `cylinder` / `circle`, `oval` | box / cylinder / disc |
| the root's `label` | workflow `main`'s title |

Keys match case-insensitively, repeated keys merge with the last write winning, and an edge to an undeclared name declares it, as in d2.

Everything else is ignored with a warning: classes, imports, globs, layers, other shapes, `near`, sizes, grid keys, arrowheads (`<->` and `--` become one-way edges), `direction` other than `right`, and root fields other than `label`, `vars` and `direction`. Other `style.*` keys are accepted and not drawn. An edge between a component and its own ancestor or descendant is dropped with a warning: svugy can't draw it.

## Workflow `main`

d2 has no workflows, so `render`, `validate` and `import` read a d2 file as one:

- workflow `main`, titled with the root's `label`, else `main`; its subtitle is `vars.svugy.subtitle`;
- one step, `main: Every edge`, listing every edge in written order, then every leaf no edge touches, so the import draws everything d2 drew;
- each shape's `vars.svugy.position` and its `direction: right` become `main`'s [overrides](markdown.md#overrides).

## svugy features in d2

d2 accepts extra keys only in `vars`, so svugy's own features go in `vars: { svugy: { … } }`. The file stays valid d2.

On a shape:

| Key | Value |
|---|---|
| `caption` | text |
| `shape` | `box`, `slab`, `cylinder`, `disc` |
| `height` | number |
| `position: { x; y }` | numbers: an override in workflow `main` |
| `badge` | `true`: badge every edge into this leaf |

On the root, `subtitle` (text) is workflow `main`'s subtitle.

Any other key there is an error; d2 itself never reads `vars`, so it wouldn't catch the typo. A legend, svugy's v3 `vars.svugy.legend` or d2's `vars.d2-legend`, is an error.

What d2 can't say at all, write in Markdown: more than one workflow or step, workflow and step prose, travelers, one badge per edge, `grid`/`row`/`column` layouts, `meta.NAME` lines and shared styles.

## Import to Markdown

`svugy import my.d2 -o my.md` writes workflow `main` as a `## Workflows` section, its overrides included, and every property out, so repeated fills stay repeated: factor them into frontmatter `styles` by hand. If any part can't be written as Markdown (a key with a space, an unusual dash, an unknown style key), import lists every such part, writes nothing and exits `1`.
